# Anthropic Training

A public record of self-directed learning through **official, publicly available Anthropic / Claude training** only.

This repository is not a certification and not an Anthropic-endorsed curriculum. Course order follows Anthropic's catalog groupings and is not a mandated sequence.

## Source-of-truth rule

- Versioned Markdown in this repository is the source of truth.
- GitHub Issues may be used for individual course tasks (see the "Course task" issue template).
- A GitHub Project board is optional. It is only a view over the work, not the canonical curriculum.

## Keeping it current

Every catalog or credential update records the primary Anthropic source URL and the access date.
